# Employee Performance Predictor Using Data Analytics

An end-to-end data analytics and machine learning project that explores employee performance patterns and predicts performance categories using historical review data.

## Project Overview

This project analyzes employee-related features, identifies performance patterns, compares machine learning models, and presents the results through an interactive Streamlit dashboard.

The project uses a **synthetic dataset** for educational and demonstration purposes.

## Objectives

- Analyze employee performance trends using exploratory data analysis (EDA).
- Identify relationships between work-related features and performance categories.
- Build and compare machine learning classification models.
- Visualize model performance and feature importance.
- Provide an interactive dashboard for exploring data and testing predictions.

## Features

- Synthetic employee dataset generation
- Data cleaning and quality checks
- Exploratory data analysis and visualizations
- Logistic Regression and Random Forest model comparison
- Employee-grouped train/test split to reduce employee-level data leakage
- Confusion matrices and classification metrics
- Feature importance analysis
- Interactive Streamlit dashboard
- Prediction interface with class probabilities
- Automated tests using pytest

## Machine Learning Models

Two classification algorithms are evaluated:

1. **Logistic Regression**
2. **Random Forest Classifier**

The models are compared using accuracy, macro F1-score, precision, recall, and confusion matrices.

### Model Results

| Model | Accuracy | Macro F1-score |
|---|---:|---:|
| Logistic Regression | 62.75% | 63.64% |
| Random Forest | 60.00% | 60.74% |

Logistic Regression achieved the higher accuracy and macro F1-score on the current test split. These results apply only to this synthetic dataset and are not evidence of real-world employee assessment accuracy.

## Dataset

The project contains 2,000 synthetic review records representing 1,000 employees across two review cycles.

The target variable is `perf_band_next`, which represents the next performance category:

- **Low**
- **Medium**
- **High**

Features include department, job level, experience, project workload, task delays, on-time delivery, code review scores, training, certifications, peer feedback, and other work-related indicators.

The dataset is artificially generated and does not contain real employee records.

## Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/vinotha2007-V/Employee-Performance-Predictor-using-Data-Analytics.git
```

### 2. Navigate to the project folder

```bash
cd Employee-Performance-Predictor-using-Data-Analytics
```

### 3. Create a virtual environment

```bash
python -m venv .venv
```

### 4. Activate the environment on Windows

```cmd
.venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the dashboard

```bash
streamlit run app.py
```

Open the local URL shown in the terminal, usually `http://localhost:8501`.

**Note:** The dashboard requires the dataset, trained model files, metrics, and feature-importance outputs generated by the project. If any of these files are not included in the repository, generate them using the corresponding project scripts before running the dashboard.

## Run Tests

Run the test suite from the project root:

```bash
python -m pytest -v
```

## Limitations and Responsible Use

This is an educational portfolio project built with synthetic data. Its predictions are not validated for real employee performance assessment.

Feature importance shows model associations, not causation. The project must not be used to make decisions about hiring, promotion, compensation, discipline, or termination. Real-world use would require representative data, rigorous validation, fairness assessments, privacy protections, and appropriate human oversight.
